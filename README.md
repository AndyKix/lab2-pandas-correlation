# Лабораторная №2. Pandas и корреляции

Решение задания по анализу данных Titanic и brainsize.

- [pandas_tasks.py](pandas_tasks.py) — первая часть, Titanic.
- [correlation_tasks.py](correlation_tasks.py) — вторая часть, корреляции.
- [report.ipynb](report.ipynb) — расчёты, графики и выводы в ноутбуке.
- [report.md](report.md) — отчёт для просмотра без Jupyter.
- [TASK.md](TASK.md) — исходное задание.

Ноутбук запускается из корня репозитория. Библиотеки перечислены
в `requirements.txt`, данные лежат рядом с кодом.
